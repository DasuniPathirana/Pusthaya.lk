# Pusthaya.lk

A creative e-commerce storefront for school books, stationery, personalised gifts, printing and special quotations.

**Stack:** Next.js, TypeScript, Supabase PostgreSQL/Auth/Storage, Cloudflare Workers.

The storefront and admin dashboard are maintained in a single Next.js project. Admin access uses assigned roles enforced through Supabase Row Level Security.

Status: implementation in progress. No live payments or production deployments.
